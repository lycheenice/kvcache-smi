# KVCache-SMI 编码技能索引

本索引汇总了可直接用于本项目实现阶段的技能包：

1. `skills/kvcache-cli-api-bootstrap`
   - 目标：搭建代码骨架、统一 schema、统一 CLI/API 约定。
2. `skills/kvcache-estimator-impl`
   - 目标：实现 KV Cache 静态估算与容量反推。
3. `skills/kvcache-monitor-impl`
   - 目标：实现实时监控、分层统计与开销控制。
4. `skills/kvcache-benchmark-impl`
   - 目标：实现带宽测试与场景化优化建议。

建议使用顺序：
1) CLI/API Bootstrap
2) Estimator
3) Monitor
4) Benchmark
